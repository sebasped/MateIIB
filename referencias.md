# Bibliografía, material y recursos

## Para Python y Programación

- [Videos uso básico Python del profe Ignacio Ojea](/material/python_uso_basico.md).
- [Curso de Python de UNSAM](https://github.com/python-unsam/programacion1/blob/main/Notas/Contenidos.md).
- {cite}`BatistaCarlevaro`: las partes I y II tienen una excelente y completa introducción a Python y Programación.
- {cite}`Kong2020`: la [parte I](https://pythonnumericalmethods.studentorg.berkeley.edu/notebooks/Index.html#part-i-introduction-to-python-programming) de este libro online sirve como referencia general para aprender a programar en Python.
- [Python for Biologists](https://www.pythonforbiologists.org/): colección de videos, código y ejercicios, para aprender Python a través de ejemplos de genómica.
- {cite}`10.1371/journal.pcbi.1004867`: aprender Python con mirada Biocientífica. Se puede descargar.
- [Think Python, Allen Downey](https://allendowney.github.io/ThinkPython/): excelente referencia para aprender Python. Cada capítulo incluye Jupyter NBs con ejemplos y ejercicios.
- [Más libros de Python de Allen Downey](https://greenteapress.com/wp/): más libros de este autor. Todos se pueden descargar o leer online, e incluyen tantos explicaciones como Jupyters NBs.
- [Tutorial de la documentación oficial de Python](https://docs.python.org/3/tutorial/index.html).

## Para la materia propiamente dicha
- [Apunte teórico de la materia](/material/Mate_II_Biologia_apunte.pdf).
- {cite}`Prunello2024`: excelente material online que mezcla explicaciones, ejemplos y Python. Sigue el espíritu de nuestra materia y cubre varios temas.
- {cite}`Arevalo2021`: muy buen libro que sigue el espíritu de nuestra materia, y además tiene un apéndice con código Python de los temas del libro.
- {cite}`BatistaCarlevaro`: otro muy buen libro que mezcla teoría, ejemplos y Python. La parte III incluye varios temas de nuestra materia.
- {cite}`Kong2020`: la [parte II](https://pythonnumericalmethods.studentorg.berkeley.edu/notebooks/Index.html#part-ii-introduction-to-numerical-methods) de este libro online sigue bastante el espíritu de la materia. Mezcla explicaciones con código Python, y curbre casi todos los temas de nuestra materia.
- {cite}`Mora2015`: excelente libro que cubre varios temas de nuestra materia. Tiene muchos ejemplos resueltos, tanto en papel como programando. Usa {term}`R` en vez de Python, pero de todos modos sigue bien el espíritu de nuestra materia.

## Recursos varios de interés
- [Biopython](https://biopython.org/): herramientas en Python para Biología Computacional.
- [Teach Yourself Computer Science](https://teachyourselfcs.com/): recursos de programación y computación propiamente dichos, para aprender literalmente casi todo.
