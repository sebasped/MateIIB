# Glosario

:::{glossary}

Jupyter Notebook
: Entorno de programación que combina texto y código. En Python se llaman Jupyter Notebooks. Se abrevian NB (de `N`ote`B`ook) y los archivos son `.ipynb` (`i`nteractive `py`thon `n`ote`b`ook). [Sitio oficial](https://jupyter.org/).

Python
: Lenguaje de programación. [Sitio oficial](https://www.python.org/).

R
: Lenguaje de programación. [The R Project for Statistical Computing](https://www.r-project.org/).

:::
